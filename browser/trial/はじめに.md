# SpecQR Reader ブラウザー試験版

実際の C++17 Reader を WebAssembly で実行する、実験的なローカル試験版です。選んだ画像や復号結果を外部サービスへ送信しません。

## 起動前の確認

このフォルダーに `assets/specqr.mjs` と `assets/specqr.wasm` の両方があることを確認してください。

- ソースリポジトリをチェックアウトした場合、この 2 ファイルはまだありません。リポジトリ内の `browser/README.md` に従い、Emscripten 6.0.12 で `browser/trial/assets/` へビルドしてください。
- ビルド済みの試験版フォルダーを受け取った場合は、両方が含まれていれば再ビルドは不要です。ブラウザーでの試用に Emscripten は不要です。

ローカル HTTP サーバーの起動には Python 3 を使用します。サーバーはファイルの配信だけを行い、QR の解析はブラウザー内の Reader が行います。

## 同じコンピューターのブラウザーで起動する

1. アーカイブから入手した場合は、フォルダー全体を展開します。
2. ターミナルで、この説明書と `serve.py` があるフォルダーへ移動します。macOS では `cd ` と入力し、フォルダーをターミナルへドラッグして Return を押す方法も使えます。
3. `python3 serve.py` を実行します。
4. 表示された `http://127.0.0.1:8765/` を、同じコンピューターのブラウザーで開きます。
5. サンプルまたは PNG/JPEG ファイルを選び、「読み取り」を押します。「停止」は Worker ごと終了し、次の読み取りで新しい Worker を使用します。
6. 終了時は、サーバーを起動したターミナルで Control+C を押します。

ポートが使用中なら、`python3 serve.py --port 8766` で起動し直し、表示された URL を開いてください。HTML ファイルを直接開く `file://` の方法では Worker と Wasm を読み込めません。サーバーは `127.0.0.1` にのみバインドするため、他の端末からこの URL へアクセスすることはできません。常駐登録、シェル設定、ファイアウォール設定の変更は不要です。

macOS で `/usr/bin/python3` が使える場合は、`launch.command` も起動に使用できます。この補助スクリプトは `/usr/bin/python3` を明示的に呼ぶため、その場所に Python 3 がない環境では、使用可能な Python 3 で `serve.py` を実行してください。

## 画像と結果

- PNG/JPEG の展開は、ブラウザーの画像機能と Canvas を使用します。得られた RGB 配列を Wasm の `read_image()` に渡します。画像の展開と QR の復号は別の処理です。
- 透過画素は白背景へ合成します。色管理と画像の向きはブラウザーの処理に従います。アプリケーションでの自動縮小は行いません。画面上のプレビューは表示倍率だけを調整します。
- 画像は各辺 8192 px 以下、合計 16,777,216 画素以下、ファイルは 64 MiB 以下に制限します。上限以内でも、ブラウザーの資源不足などで処理できない場合があります。
- `bytes_hex` が元のバイト列です。ECI、FNC1、Structured Append、各セグメント、検出した四隅を保持します。補助の ASCII 表示は、印字可能な ASCII 以外とバックスラッシュをエスケープし、文字コードを推測して変換しません。
- 検出した URL はリンクとして実行せず、ペイロードを HTML として挿入しません。「JSON を保存」で Reader の結果を保存できます。
- `not_found` は未検出です。処理上限への到達は通常の完了と区別し、取得できた部分結果も表示します。`error`、`symbols`、`work_limit_reached` を合わせて確認してください。

## 試験版の範囲

カメラ、文字コードの自動変換、Structured Append の再結合、公開ホスティングは含みません。Wasm 化は既存 Reader の画像認識性能を改善するものではなく、ぼけ、傾き、撮影条件などによる限界があります。Mac の Chrome や Safari で動作しても、iPhone/iPad での動作確認を意味しません。

開発者向けの再現方法は [検証ハーネスの説明](tests/README.md)、コードと同梱データのライセンス・来歴は [第三者由来の情報](THIRD_PARTY-Reader.md) を参照してください。実際に検証したブラウザー、バージョン、結果は、対象のソースと Wasm に対応する検証記録で確認してください。
